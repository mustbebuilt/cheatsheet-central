# Cheatsheet Central

A small repository of quick-reference cheat sheets for common developer topics.

This repo is meant to help beginners and busy developers quickly find the most useful commands, concepts, and workflows without digging through long tutorials.

## Included cheat sheets

- [excel-basics.md](excel-basics.md) — beginner Excel formulas and data preparation tips
- [github.md](github.md) — GitHub and Git basics for new developers
- [markdown.md](markdown.md) — common Markdown syntax for README files and docs
- [vscode-shortcuts.md](vscode-shortcuts.md) — VS Code shortcuts grouped by skill level
- [working-with-images.md](working-with-images.md) — tips for working with images in projects and documentation

## Purpose

The goal of Cheatsheet Central is to keep learning simple:

- quick to scan
- practical for real work
- focused on the essentials
- useful in VS Code, on GitHub, and during day-to-day development

## Open for suggestions

This repo is intentionally lightweight and easy to extend.

If you have an idea for a new cheat sheet, feel free to suggest topics.
