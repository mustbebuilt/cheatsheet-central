# Shortcut Keys Cheat Sheet (with some Visual Studio Code Helpers)

A quick starter guide for developers who want to use VS Code faster without learning everything at once.

Think of it like leveling up: start with the basics, then unlock more advanced shortcuts as you go.

---

## Easy Mode

These are the first shortcuts to learn.

| Action | Shortcut |
| --- | --- |
| Cut | `Ctrl+X` |
| Copy | `Ctrl+C` |
| Paste | `Ctrl+V` |
| Save file | `Ctrl+S` |
| Open Command Palette | `Ctrl+Shift+P` |
| Quick open file | `Ctrl+P` |
| Find in file | `Ctrl+F` |

## Best beginner habit

If you only remember a few shortcuts, keep these:

- `Ctrl+S` — save
- `Ctrl+P` — open a file
- `Ctrl+F` — search in the current file
- `Ctrl+Shift+P` — command palette
- `Ctrl+C` / `Ctrl+V` — copy and paste
- `Ctrl+X` — cut

That is enough to make editing feel much faster right away.

> The main win for new developers is learning the shortcuts that reduce mouse use and keep your hands on the keyboard.

## Appendix: Mac users

On a Mac, use `Cmd` where this guide shows `Ctrl` for most shortcuts.

| Action | Windows/Linux | Mac |
| --- | --- | --- |
| Cut | `Ctrl+X` | `Cmd+X` |
| Copy | `Ctrl+C` | `Cmd+C` |
| Paste | `Ctrl+V` | `Cmd+V` |
| Save file | `Ctrl+S` | `Cmd+S` |
| Find in file | `Ctrl+F` | `Cmd+F` |
| Open Command Palette | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Quick open file | `Ctrl+P` | `Cmd+P` |
| Toggle sidebar | `Ctrl+B` | `Cmd+B` |
| Open Search | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Toggle comment | `Ctrl+/` | `Cmd+/` |

### Other Mac keys

- `Option` usually replaces `Alt`, for example `Shift+Option+F` to format a document.
- `Control+`` opens the VS Code terminal.
- `Cmd+Z` undoes an action.
- `Cmd+Shift+Z` redoes an action.
